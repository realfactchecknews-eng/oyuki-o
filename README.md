# ОЮКИ-О

Сатирический сайт вымышленного Очковского юридического колледжа-интерната для особо одарённых детей из глубинки. Один файл `index.html`, без сборки и зависимостей.

Разделы: главная, сведения об организации, абитуриенту, образование, локальные акты, мероприятия, интернат, руководство, наука, антикоррупция, обращения, вопросы.

Все организации и лица вымышлены.
